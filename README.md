# New Dubai Nursery

A modern website for New Dubai Nursery Early Learning Center, built with the same frontend stack as `styleeditbyreena`:

- Next.js 16 App Router
- React 19
- Tailwind CSS 4
- Plain JavaScript (ES modules)
- Vercel Analytics

## Local development

```bash
npm install
npm run dev
```

Then visit `http://localhost:3000`.

## Production check

```bash
npm run build
```

## Content notes

Official New Dubai Nursery photography and downloadable admission forms are stored in `public/`. Shared contact details, the Al Hudaiba address and Google Maps links are maintained in `app/lib/site-data.js`.
